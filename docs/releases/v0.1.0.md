# JSON Workbench v0.1.0

First downloadable release for macOS 13+, with a universal Apple Silicon / Intel app.

- Single JSON pane by default; a JavaScript transform reveals the live result pane.
- Automatic formatting on load, paste, and copy; copying preserves the original input and comments.
- JSON / JSON5 / YAML / XML input, conversion, precise JSON number tokens, and sandboxed local transforms.
- Clear Collapse / Expand controls, native Open / Save, and a persistent always-on-top option.
- Raycast Script Command launches the downloaded app with clipboard input, JSON text, or a local file.
- Full Raycast extension source and prebuilt helper included separately for Preview JSON and selected-text input.

## Downloads and installation / 下载与安装

**Recommended / 推荐:** `JSON-Workbench-v0.1.0-macos-universal.dmg` — drag the app to Applications, copy the included **Raycast Scripts** folder to a permanent location, and add it using **Raycast Settings → Script Commands → Script Folders → +**. No Node.js or Xcode needed. Then search **Open JSON Workbench**.

**Full extension / 完整扩展:** `JSON-Workbench-v0.1.0-raycast-extension.zip` — requires Node.js 22+. Extract, run `npm ci` then `npm run dev`; includes **Open JSON Editor** and Raycast's native **Preview JSON**. The native app is already compiled.

**Integrity / 校验:** download `SHA256SUMS.txt` into the artifact folder and run `shasum -a 256 -c SHA256SUMS.txt`.

The app is ad-hoc signed and **not Apple notarized**. macOS may block its first launch; after verifying and trusting the download, use **System Settings → Privacy & Security → Open Anyway** according to [Apple's instructions](https://support.apple.com/en-us/102445).

应用未经过 Apple Developer ID 签名或公证；首次运行可能需要在“系统设置 → 隐私与安全性 → 仍要打开”中确认。编辑器及脚本免编译安装；Raycast 内部树状预览需要上方完整扩展源码安装。

See the [English / 中文 installation guide](https://github.com/Stxr/raycast-json-preview/blob/v0.1.0/docs/install.md). Store publication is a separate review process; this release can be used without the Store. Runtime UI checks were performed on Apple Silicon; the Intel build is compiled and inspected but has not been tested on Intel hardware.
